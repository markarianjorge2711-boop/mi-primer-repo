# mi-primer-repo

Mi primer repositorio de prueba con Claude Code.

## Acerca de

Este repositorio fue creado como ejercicio para aprender a usar GitHub con Claude Code, incluyendo:

- Crear repositorios desde la terminal
- Trabajar con ramas (branches)
- Abrir Pull Requests

## Cómo empezar

```bash
git clone https://github.com/markarianjorge2711-boop/mi-primer-repo.git
cd mi-primer-repo
```
